外部ECを想定した商品ページ（サイズごとに試着ホスト）

開き方：FIT&LOOK コンソールを http://localhost:3000 で起動し、本ページを http://localhost:3000/demo-embedded-ec.html で開いてください（widget.js と API と同一オリジンにします）。

許可ドメイン：コンソールの Widget キーに localhost（または 127.0.0.1）を含めてください。さもなくば /api/public/widget-config が 403 になります。

本番 CDN：EC サイトではコンソールの「埋め込み」に表示される NEXT_PUBLIC_WIDGET_CDN_URL（未設定時はコンソールのオリジン + /widget.js）を <script async src="…"> に指定し、API はコンソールのオリジンを data-fitlook-api-url で明示すると安全です。

下のプレースホルダーを差し替え：有効な public_key と、コンソール商品に登録済みの external_product_id に置き換えてください。
